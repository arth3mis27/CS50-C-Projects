# CS50-C-Projects
Bu depo, Harvard CS50x eğitimi kapsamında C dili ile geliştirdiğim temel seviye bellek yönetimi (memory management), dosya okuma/yazma (file I/O) ve veri yapıları algoritmalarını içermektedir.

Hedef:
Elektrik-Elektronik Mühendisliği 4. sınıf öğrencisi olarak; TÜBİTAK 2209-A kapsamında geliştireceğim kontrol sistemleri ve donanım/yazılım entegrasyonu projeleri için gerekli olan düşük seviyeli (low-level) C programlama altyapısını bu projelerle pratik ettim.

İçerik:

Recover: RAW formatındaki bir bellek imajından, bit seviyesinde (byte-level) okuma yaparak silinmiş JPEG dosyalarını kurtaran veri kurtarma programı.

Filter: Resim dosyalarının piksellerine matris işlemleri uygulayarak görüntü işleme (image processing) algoritmalarının C'deki temel uygulaması.

Diğerleri: Şifreleme algoritmaları, döngüler ve bellek optimizasyonu örnekleri.
